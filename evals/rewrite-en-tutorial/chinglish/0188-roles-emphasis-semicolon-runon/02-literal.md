Different roles emphasize different levels, too. Backend engineers get tested on all three, leaning more toward level 3 the more senior they are; for frontend and mobile engineers, level 1 matters a lot (the object model of state, components, and data flow), level 2 is mostly about client-side building blocks (local cache, push notifications, CDN), and level 3 rarely goes deep on the server side; for data engineers and ML engineers, level 1 is about data modeling and the abstract structure of pipelines, while level 3 focuses on the concrete tech stack for data platforms and model serving; DevOps and SRE engineers weigh level 2 and level 3 roughly equally, focused on infrastructure and operational building blocks.
