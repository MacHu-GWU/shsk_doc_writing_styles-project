This method isn't limited to building documentation experts. Say, for example, I wanted to automatically track the latest papers or news in some field every day and generate a daily digest. I'd use the exact same approach: first check whether that information source publishes its own machine-readable index, something like `llms.txt`, most serious sources do. Once you find it, don't trust it blindly, verify first whether it's a stable, officially sanctioned mechanism. Once confirmed, turn that discovery process into a Skill that fetches the latest entries fresh every time, instead of me manually checking every day. Then test it against a few topics it's never seen before, to confirm it's actually pulling accurate results. It's the exact same skeleton used to build the Claude Code expert, just pointed at a completely unrelated domain, and it still works.
