When you're done, you'll be able to create and configure a repository of your own, edit files and commit changes right there in the browser, open a branch to run an experiment safely off to one side, and bring the results back to main through a Pull Request. You'll also know the difference between public and private, how to invite a collaborator, and how to hand a program an access token so it can act for you. Then the whole workflow moves onto your own machine with GitHub Desktop. And it'll click that every repository sits under an owner, which is what tells you to look inside an organization for the things people have shared with you. This is the workflow real teams run every day. Get it down and you've got the groundwork for joining any modern collaborative project. The course stops at the basics, with just enough depth to cover "going one full round entirely on your own".
